# 2.17.0 破坏性与迁移

> 本版导航：[版本说明](./announcement.md) · [变更汇总](./changelog.md) · **破坏性与迁移**

本版无业务可感知的破坏性变更。

## 扫描依据

[2.16.0...2.17.0](https://github.com/Tencent-TDS/KuiklyUI/compare/2.16.0...2.17.0) 共 58 个 compare commit，GitHub Release 的 `What's Changed` 也收录 58 个条目。已按业务能力面逐项核对，并重点检查了新增公开能力及可能改变既有契约的改动：

- 属性 / 事件 / 内置组件 / 内置 Module：本版主要为新增能力，没有发现删除或不兼容签名变化。
- 路由 / `@Page` / 页面注解契约：未发现已有页面写法失效。
- 默认行为：#1045 增加了键盘收起控制入口，但未删除原有能力；未显式设置时各端原有默认差异仍保留。
- Compose Navigation、Drawer、RecompositionProfiler、列表复用及跨端宿主修复：均未发现业务侧必须迁移的既有契约变化。
- #1198 移除的是内部实现字段 / 私有函数，不涉及业务公开 API；文档、示例和工程杂项不构成 breaking。

结论：本版无需要业务迁移的破坏性变更，可直接升级。
