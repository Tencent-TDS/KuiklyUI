# 2.27.0 版本说明

> 本版导航：**版本说明** · [变更汇总](./changelog.md) · [破坏性与迁移](./breaking.md)

2.27.0 主要聚焦多模块工程的页面名重复检测、鸿蒙宿主配置能力与多端稳定性修复。

## Kuikly DSL

### 能力增加

- **鸿蒙同步任务告警阈值可配置（鸿蒙）**：宿主可以按调试或性能场景调整同步任务的告警超时时间，默认行为保持不变。调用 `KRSetSyncMainTaskWarnTimeout(int ms)` 设置阈值，建议在 Kuikly 初始化前完成配置（#1720）。

### Bug 修复

本版修复了 iOS TurboDisplay 刷新未遵循节点级过滤、鸿蒙双击手势崩溃、鸿蒙配置变化后文本未刷新、鸿蒙窗口调用稳定性以及 H5 tabs indicator 显示异常等问题，详情见「变更汇总」对应端的条目。

## Compose DSL

### 能力增加

- **重复页面检测（多模块）**：多模块工程中同名 `@Page` 页面会在编译阶段直接失败，帮助尽早发现重复页面，避免运行时路由覆盖（#1426）。

## 升级建议

升级前请检查项目中是否存在同名 `@Page` 页面；本版会将这类问题提前暴露为编译失败，具体变化和迁移方式见[破坏性与迁移](./breaking.md)。
