# 2.27.0 版本说明

> 本版导航：**版本说明** · [变更汇总](./changelog.md) · [破坏性与迁移](./breaking.md)

2.27.0 以稳定性修复为主，另有多模块注册与鸿蒙宿主能力增强。

## Kuikly DSL

### 能力增加

- **鸿蒙同步任务超时可配置**：新增 `KRSetSyncMainTaskWarnTimeout(int ms)`，主↔worker 同步任务的死锁检测阈值从硬编码 10s 变为可配置（默认值不变）。注意该接口未做线程同步保护，只应在 Kuikly 初始化前调用一次（#1720）。

### Bug 修复

修复 iOS TurboDisplay 刷新、鸿蒙双击手势崩溃、鸿蒙 config change 文本未刷新、H5 tabs indicator 显示等问题，逐条见「变更汇总」。

## Compose DSL

### 能力增加

- **多模块页面注册**：新增 `@KuiklyModulePages` 注解与配套 KSP 处理器，子模块在编译期生成页面注册表，主模块扫描后统一收口，多模块工程不再依赖手工维护清单（#1426）。

## 升级建议

本版存在一项条件性变更：同名 `@Page` 页面会直接编译失败（此前为运行时静默覆盖），升级前请先阅读「破坏性与迁移」。
