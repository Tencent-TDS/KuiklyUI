# 2.27.0 破坏性与迁移

> 本版导航：[版本说明](./announcement.md) · [变更汇总](./changelog.md) · **破坏性与迁移**

## 条件性破坏性

### #1426 同名页面直接编译失败：重复 `@Page` 页面名不再静默覆盖

- 变化：以前多个页面使用同一个 `@Page` 名字时，编译可以通过，运行时后注册的页面可能静默覆盖先注册的页面；现在会在编译阶段直接失败，并指出冲突页面。
- 触发条件：项目中存在同名 `@Page` 页面；启用多模块工程时，主模块会连同子模块页面一起检查。
- 迁移：按编译报错将冲突页面名改为全局唯一即可。
- 证据：[#1426](https://github.com/Tencent-TDS/KuiklyUI/pull/1426)
