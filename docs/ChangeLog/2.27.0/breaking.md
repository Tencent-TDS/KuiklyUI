# 2.27.0 破坏性与迁移

> 本版导航：[版本说明](./announcement.md) · [变更汇总](./changelog.md) · **破坏性与迁移**

## 条件性破坏性

### #1426 同名页面直接编译失败：重复 @Page 页面名不再静默覆盖

- 变化：以前两个页面使用同一个 `@Page` 名字，编译能通过，运行时后注册的页面会悄悄覆盖先注册的；现在编译期直接失败，并指出冲突的页面名和对应类。
- 触发条件：项目中存在同名的 `@Page` 页面；多模块工程中主模块会连同子模块一起检查。
- 迁移：按编译报错把冲突的页面名改成唯一的即可，无其他代码改动。
- 证据：#1426
