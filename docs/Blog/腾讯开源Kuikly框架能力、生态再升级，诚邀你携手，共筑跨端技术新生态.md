# 腾讯开源Kuikly框架能力、生态再升级，诚邀你携手，共筑跨端技术新生态

### 前言

自开源以来，Kuikly跨平台框架获得了开发者的广泛认可与青睐，并已在众多业务中成功落地。在此过程中，社区对生态建设的呼声也日益增强，通过GitHub Issue、社区群等渠道，我们深刻感受到了大家对完善生态的强烈期待。

经过半年多的持续建设，Kuikly框架能力持续提升，生态体系现已初步成型，基础设施日益丰富。现在，已经有非常多热心的社区伙伴加入我们，一起贡献力量。同时，我们也同步建立了相应的荣誉与激励措施——在这里，你不仅可以与核心团队直接交流，还有机会获得丰富的Kuikly定制好礼。我们真诚欢迎更多开发者加入社区，和我们一起，把 Kuikly 生态建设得更加繁荣！

### Kuikly迭代加速，框架能力持续增强完善

自开源以来，Kuikly框架始终以GitHub作为迭代仓库，保持快速版本迭代，并持续进化。我们通过社区的各交流渠道，倾听用户声音、了解开发者需求，并结合框架自身规划，将需求和规划能力不断融入Kuikly版本路线。在Kuikly团队与社区开发者的协同努力下，我们近期推出了多项能力优化和新特性支持，持续完善框架功能与配套工具体系，进一步提升开发体验与工程效率：

- **Kotlin版本适配和构建工具链：**

○ Kotlin2.1支持。完成对Kotlin2.1版本适配支持， Kotlin 新版本为开发者带来了多项优化与特性增强。

○ Windows/Linux编译支持**。**KuiklyBase 与 KuiklyUI 均已完成 Windows 和 Linux 平台的编译适配，进一步扩大了非 Mac 平台的开发者受众，开发者可参考官方文档完成适配。

- **Compose/Kuikly DSL：**

○ 新增支持LifeCycle、ViewModel。使用 ViewModel 可以更好地封装业务逻辑，缓存状态，并可在配置更改后持久保留相应状态。

○ 支持资源管理能力：轻松使用跨端图片、字体和字符串资源

○ AI Chat组件支持。支持Markdown渲染组件，并提供AI Chat示例场景。

○ 支持跨端无障碍设置。

- **H5端：**

○ PC 浏览器支持，实现主流PC浏览器（Chrome、Safari）的组件适配。

○ SPA单页应用模式支持，实现流畅的页面切换和状态保持。

○ 支持按 js + webpack 接入，提供前端技术栈友好的构建配置。

- **小程序端：**

○ 支持页面分包，提供分包过大的解决方案。

○ 支持uniapp/小程序页面互调，提供了渐进式引入Kuikly小程序的方案。

- **液态玻璃适配：**

苹果 9 月推出 “液态玻璃（Liquid Glass）” 新特性后，Kuikly 第一时间完成了该特性的视觉与交互适配，助力业务实现更优质的跨端体验。

- **其他迭代中能力：**

其他社区对框架能力的诉求，如Mac渲染适配、UI Preview、多屏幕适配、多语言支持等能力，当前已在规划开发中，敬请期待。

**在issue解决方面**，开源后有 330+ 个 issues 被开启，在 Kuikly 团队和社区的共同努力下，已经关闭了 290+ 个，剩余40+ issues 会在后续迭代中持续跟进解决。在Issue处理节奏上，我们基本保持着1~2周内响应并确认问题的节奏，整体待解决issue维持在较低的水平，确保了开发者关注问题能及时得以跟进。

**在PR方面，**从开源以来半年左右的周期，总共提交了 460+ 次 PR，团队平均每周提交超过20+ Commits。当前已有近30位开发者参与PR贡献，其中半数以上来自社区。

在保障版本质量与稳定性的前提下，Kuikly 始终保持着高效的迭代节奏，切实解决开发者日常使用痛点，优化开发体验。目前已发布16+版本，基本保持了月均2+版本发布的节奏。

社区开发者的积极参与，共同推动了框架的快速演进与功能完善。

### 推出全新组件市场和知识共享平台，社区生态初成长

生态是开源框架的核心生命力，组件和技术实践知识的丰富度，直接决定了开发者的使用体验与框架的落地效率。为响应社区核心诉求，我们打造了组件市场与知识共享平台两大载体，为生态搭建起坚实的基础。

#### 组件市场：一站式资源库，让开发更高效、更便捷

为方便开发者浏览和检索社区贡献的各类组件（包括基础组件、业务组件、UI 组件、工具库等），Kuikly 社区提供了统一的组件聚合市场：

[Kuikly组件市场](https://kuikly.tds.qq.com/third-party?tab=component)

该市场汇聚了所有与 Kuikly 兼容的开源库，为你提供一站式资源平台，帮助你轻松找到适用于 Kuikly 项目的各类组件与工具。

![](https://mmecoa.qpic.cn/mmecoa_png/tnZGrhTk4dcXiaGkhSMsibiausEjtqSL6WwBwKt58VU1ZX6WCt9HU7ItI71icHHIKSfDlKhuu5I5ctRJbLTdRz9O2Q/640?wx_fmt=png&from=appmsg)

当前，Kuikly组件市场已收集到近25个高质量组件，覆盖了常用基础组件品类。除KuiklyBase提供的组件外，其他超半数组件均由社区开发者提供：

#### 知识共享：建立社区实践共享平台，共建学习交流生态圈

社区技术实践分享是开源项目的 “活水” 与 “灵魂”，也是 Kuikly 生态建设的重点板块。它既能帮助开发者跨越学习门槛、获取实战经验，也能让分享者沉淀技术、建立个人影响力，是激发社区协作、推动生态正向循环的基础。

Kuikly 搭建了技术分享聚合平台，通过专属收集机制收录社区开发者的优质技术文章，方便开发者检索查阅。目前，平台已收录 15 + 篇技术文章，覆盖架构设计、MVVM 实践、多 Module 管理、性能优化、问题排查等多个领域。

![](https://mmecoa.qpic.cn/mmecoa_png/tnZGrhTk4dcXiaGkhSMsibiausEjtqSL6WweByfc9Eice9rcfVDSBvFmvZOl8uNiabibU6wFcjiachcwO0FyPKUicCpa2g/640?wx_fmt=png&from=appmsg)

除社区共享平台已收录的优质文章外，在掘金、CSDN、知乎等第三方技术社区，Kuikly 相关分享也日趋丰富，这些文章从不同角度分享了Kuikly的使用经验和最佳实践，为社区提供了宝贵的学习资源。

### 建立社区荣誉激励机制，持续贡献赢Kuikly专属好礼

当前社区已迈出坚实的第一步，但整体内容生态尚处于成长初期，组件品类、实战案例、特性支持、issue解决等方面仍需更多共建力量参与。为构建可持续、高活力的 Kuikly 开源生态社区，凸显每一位贡献者的参与价值，参照成熟开源社区的运行机制，我们制定了贡献者持续、深度参与的激励机制。

#### 社区荣誉奖励：

我们根据贡献者的参与深度与持续性，设置了“贡献者”与“贡献者先锋”两种荣誉头衔。我们鼓励开发者持续参与，并努力成为“贡献者先锋”。成为先锋的伙伴将享有以下专属激励与机会：

- 专属荣誉头衔。授予官方认证的 “贡献者先锋” 头衔，并颁发荣誉证书；

- 需求优先支持。提出的需求与建议将获得核心团队的优先处理与及时反馈；

- 参与核心团队交流。我们将邀请您参与项目规划等核心会议，成为 Kuikly 发展的“决策参与者”

#### Kuikly专属礼品奖励：

除荣誉激励外，我们还设立了 Kuikly 专属实物礼品奖励，旨在给予贡献者更及时、更直接的鼓励与回馈。随着你的贡献累积，将有机会获得精美定制礼品，以表达我们对您持续支持的诚挚感谢。

社区计划从26年开始，周期性对开发者在 PR 提交、组件开发、技术分享等方面的贡献进行加权统计，为每个周期内贡献突出的开发者发放专属礼品，具体规则后续可查阅社区官方公告。

### 贡献参与指引：从这里开始，与 Kuikly 共同成长

无论你是刚接触 Kuikly，还是具有丰富经验的“Kuikly老手”来说，都可以通过以下方式参与到社区建设中，为Kuikly生态添砖加瓦。

#### 组件贡献指引：

为降低组件贡献门槛，Kuikly 社区提供了清晰便捷的贡献渠道与流程，同时配套完善的适配教程，助力开发者快速上手。

- 组件市场收录渠道：开发者可在 [Kuikly-third-party](https://github.com/Tencent-TDS/KuiklyUI-third-party) 仓库以 PR 形式，提交三方组件与工具，经社区审核验证通过后，即可上架至 Kuikly 组件市场；

- 组件适配指引：针对开发者反馈的 KMP 组件适配鸿蒙经验不足的问题，社区基于已有案例整理了详细的，具体参见官方文档；

- Kuikly扩展组件教程：为方便社区共享扩展 UI 组件与 Module，社区还提供了 Kuikly 扩展组件抽离为独立库的教程，具体参加官方文档。

#### PR贡献指引

对于新入门Kuikly的开发者，建议从带有"good first issue"标签的问题开始，这些问题是社区专门为新手贡献者设计，难度较低。

当然，对于熟悉Kuikly的资深开发者，建议查看带有"Help Wanted"标签的issue参与贡献。或者有意持续参与贡献的开发者，可与Kuikly核心团队建立联系，一起参与Kuikly框架规划、新特性开发等。

#### 社区分享指引

参与技术实践分享的流程十分便捷：

- 第一步在自己的渠道，比如个人博客、三方技术社区(掘金、CSDN、知呼等)发表文章。

- 第二步，将三方社区的分享，按照Kuikly-third-party指引，提交到Kuikly社区。

欢迎将你的技术实践文章分享给我们！对于优质内容，Kuikly 团队会通过官方渠道进行转发推荐，这既是将好内容分享给更多用户，也是提升分享者个人影响力的好机会。
